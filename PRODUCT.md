# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Jekyll static site (existing dergigi.com). Games landing page is a first-class route under the existing layout system with scoped styles.

## Users

Primary: Gigi's existing audience (Bitcoin/nostr readers and followers) discovering kid-friendly pixel games he ships with his daughter. Secondary: kids and parents who land on a game URL or the `/games` hub and want something playable immediately, preferably installable on a phone.

## Product Purpose

`/games` is a hub that gets someone into one of the two live games fast. Success is a visitor starting Fly Pingu Fly or Unicorn vs Snakes within seconds, with a clear path to install either as a PWA and to find more of Gigi's work via `/projects`.

## Positioning

These are small pixel games designed with a child, published as installable PWAs at custom subdomains. The hub is not an app store or a generic indie-game portfolio; it is a personal playground that sends people straight into play.

## Operating Context

Visitors arrive from game footers (`dergigi.com/games`), the projects page, nostr, or shared links. They play in the browser; both games support PWA install for a quasi-native home-screen experience. The site uses the existing dergigi.com header and footer.

## Capabilities and Constraints

- Keep site header and footer.
- Stay inside Jekyll (no separate SPA framework).
- Link back to `/projects`.
- Live games: Fly Pingu Fly (`https://pingu.dergigi.com`, source `dergigi/fly-pingu-fly`) and Unicorn vs Snakes (`https://unicorn.dergigi.com`, source `dergigi/unicorn-vs-snakes`).
- Both are installable PWAs.
- Do not invent claims about platforms, stores, ratings, or download counts.

## Brand Commitments

- Name: dergigi / Gigi
- Voice: direct, human, lightly playful; not corporate game-marketing
- Family credit: games made with / designed by daughter where already stated on projects
- Existing game art and screenshots are the real visual proof
- `/games` matches dergigi.com aesthetics: same dark site chrome, Lora/Roboto, page layout grammar as Projects/Contact. Clean indie-games hub, no separate product brand or flashy portal skin.

## Evidence on Hand

- Live games and GitHub repos above
- Project banners: `assets/images/bitcoin/projects/fly-pingu-fly.png`, `assets/images/bitcoin/projects/unicorn-vs-snakes.png`
- Projects copy for both games on `projects.md`

## Product Principles

- Play first: the next action is always starting a game.
- Truthful credit: keep the daughter-made origin visible without turning it into a pitch deck.
- Personal site grammar: this hub belongs to dergigi.com, not a detached product brand.
- Install is secondary proof, not the headline.
- No fabricated social proof.
